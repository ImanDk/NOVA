دو تنظیم یک‌باره

۱. Action Button → ثبت سریع

برنامه Shortcuts را باز کن و یک میان‌بر با نام MIA Quick بساز.

  1. اکشن URL را اضافه کن.
  2. این آدرس را قرار بده:
https://imandk.github.io/NOVA/?mode=quick&v=91
  1. اکشن «Open URLs» را اضافه کن.
  2. Settings → Action Button → Shortcut → MIA Quick.

با فشردن Action Button صفحه ثبت سریع باز می‌شود و کیبورد آماده است.

۲. یادآوری هر شب ساعت ۰۰:۰۰

ساده‌ترین و قابل‌اعتمادترین روش بدون سرور:

  1. برنامه Reminders آیفون را باز کن.
  2. گزینه New Reminder را بزن.
  3. عنوان: «خرج‌های امروزت رو تو MIA ثبت کردی؟»
  4. Date & Time را فعال و ساعت را 00:00 بگذار.
  5. Repeat را روی Daily قرار بده.

این یادآوری حتی وقتی MIA بسته است از خود iOS اجرا می‌شود.

نکته

MIA فعلاً Voice، Cloudflare و Sync خارجی ندارد. اطلاعات اصلی داخل همین آیفون و IndexedDB نگهداری می‌شود. از Settings می‌توانی Backup JSON بگیری.
