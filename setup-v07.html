NOVADevice Bridge v0.7

اتصال NOVA به iPhone

این راه‌اندازی فقط یک‌بار انجام می‌شود. بعد از آن NOVA می‌تواند از طریق Shortcut، فرمان‌های زمان‌دار را به Calendar/Reminders آیفون منتقل کند.

۱

Shortcut اول: NOVA Bridge

  1. Shortcuts را باز کن و یک Shortcut جدید با نام دقیق NOVA Bridge بساز.
  2. ورودی Shortcut را Text/Any بگذار.
  3. اکشن Get Dictionary from Input را اضافه کن.
  4. مقدارهای type، title، startISO، alertISO و durationMin را از Dictionary بگیر.
  5. اگر type برابر event بود، با Add New Event یک Event در Calendar بساز.
  6. برای alertISO یک Add New Reminder بساز تا اعلان یادآوری جداگانه ایجاد شود.
  7. اگر type برابر reminder بود، فقط Reminder را در زمان startISO بساز.

بار اول iOS برای Calendar و Reminders اجازه می‌خواهد؛ Allow را بزن.

۲

Shortcut دوم: NOVA Action

  1. Shortcut جدید با نام NOVA Action بساز.
  2. اکشن Dictate Text را اضافه کن و زبان را Persian/Farsi انتخاب کن.
  3. یک URL بساز که انتهای آن خروجی Dictate Text باشد:
https://imandk.github.io/NOVA/?mode=action&cmd=[Dictated Text]
  1. اکشن Open URLs را اضافه کن تا همین URL باز شود.
۳

Action Button

  1. Settings → Action Button را باز کن.
  2. Shortcut را انتخاب کن.
  3. Shortcut «NOVA Action» را انتخاب کن.

بعد از این، فشار Action Button باید Dictation را شروع کند و فرمان را به NOVA بفرستد.

۴

تست

بگو: «سه‌شنبه ساعت ۱۲ باید برم دفتر». NOVA باید اول با صدای فارسی جمله را تأیید کند، سپس Event را داخل خودش ذخیره کند و NOVA Bridge را اجرا کند.
