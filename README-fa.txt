تغییرات:
- تب‌های مالی «نمای کلی / هزینه‌ها / درآمد / بودجه» Hover و Press State دارند.
- محتوای تب‌های مالی دیگر ناگهانی ظاهر نمی‌شود؛ Fade + Slide نرم دارد.
