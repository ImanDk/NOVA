MIA v1.2.0 — Manual Allocation + Clean UI

این نسخه بر پایه MIA v1.1.2 ساخته شده و دیتابیس قبلی را حفظ می‌کند:
nova_core_v06 / DB Version 3

تغییرات اصلی:
1) ثبت هوشمند درآمد بدون تغییر خودکار دارایی‌ها
- نمونه: «۳ میلیون از حقوق هیرسا دریافت شد»
- تشخیص خودکار مبلغ، نوع درآمد و منبع هیرسا
- ثبت درآمد در تاریخچه
- نمایش پیشنهاد بودجه‌بندی چهار حساب
- مبالغ پیشنهادی کاملاً قابل ویرایش هستند
- تا زمان زدن «ثبت همین تقسیم در دارایی‌ها» هیچ حسابی تغییر نمی‌کند
- امکان «فقط درآمد ثبت شود؛ فعلاً تقسیم نکن» وجود دارد

2) ویرایش و حذف تراکنش‌های مالی
- کنار هر واریز/درآمد و برداشت/هزینه دکمه ویرایش اضافه شده
- مبلغ، منبع/دسته و شرح قابل اصلاح است
- حذف تراکنش، اثر مالی آن را نیز به‌صورت اتمیک برمی‌گرداند
- برای درآمد تقسیم‌شده، حذف/تغییر مبلغ فقط زمانی انجام می‌شود که باعث منفی شدن حساب‌ها نشود

3) مدیریت دارایی حساب‌ها
- موجودی هر یک از چهار حساب همچنان قابل تطبیق دستی با بانک است
- گزینه «صفر کردن موجودی این دارایی» اضافه شده است
- حساب اصلی حذف نمی‌شود؛ فقط موجودی آن صفر می‌شود

4) مرحله شرح هزینه
- در ثبت دسته‌ای هزینه: ابتدا مبلغ وارد می‌شود
- بعد از تأیید مبلغ، برای همه دسته‌ها به‌جز «سیگار» صفحه شرح باز می‌شود
- شرح برای آن هزینه ذخیره و در تاریخچه نمایش داده می‌شود
- سیگار برای ثبت سریع، مستقیم بعد از مبلغ ذخیره می‌شود

5) خلوت‌سازی رابط
- Home فقط ثبت سریع، دارایی‌ها و کارهای امروز را نشان می‌دهد
- نمودار درآمد، جزئیات هورسان و میانبرهای تکراری از Home حذف بصری شدند و در صفحات تخصصی باقی مانده‌اند
- Work به انتخاب‌گر ساده حوزه کاری تبدیل شده و گزارش هورسان داخل بخش بازشونده قرار گرفته است
- Settings به گروه‌های بازشونده تبدیل شده تا صفحه کوتاه و متمرکز بماند

نکته نصب/به‌روزرسانی:
- فایل‌های ZIP را روی همان GitHub Pages قبلی جایگزین کن.
- داده‌های IndexedDB قبلی حفظ می‌شوند.
- Service Worker با cache جدید v1.2.0 منتشر شده است.
- بعد از آپلود، یک‌بار صفحه را Refresh کن. در iPhone اگر PWA باز بود، آن را کامل ببند و دوباره اجرا کن.
