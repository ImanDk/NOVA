MIA v0.9.3 — Planner Hover + Done Delete

تغییرات:
- سربرگ‌های «تقویم / کارهای باز / انجام‌شده» مثل بخش‌های مالی و کار دارای Hover و Press State شدند.
- جابه‌جایی بین سه سربرگ برنامه با Fade + Slide نرم انجام می‌شود.
- Active State سربرگ‌ها واضح‌تر و دارای خط گرادیانی ظریف است.
- برای کارهای انجام‌شده دکمه حذف قرمز و واضح اضافه شد.
- قبل از حذف کار انجام‌شده تأیید گرفته می‌شود.
- پس از حذف، آرشیو Done، فیلترها و لیست روز انتخاب‌شده به‌روزرسانی می‌شوند.
- بازگردانی کار انجام‌شده همچنان حفظ شده.
- دیتابیس نسخه قبلی بدون تغییر باقی مانده.
