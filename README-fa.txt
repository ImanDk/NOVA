MIA v0.8.8 — Interaction Polish

تغییرات تاییدشده:
1) ثبت سریع هزینه:
   - با لمس سیگار / کیمیا / بنزین / خودرو / ... پنجره مبلغ باز می‌شود.
   - عنوان دسته داخل پنجره نمایش داده می‌شود.
   - فوکوس مبلغ بعد از بازشدن نرم Sheet انجام می‌شود.
   - ثبت هزینه از حساب جاری و بودجه همان دسته انجام می‌شود.

2) قفل Zoom:
   - Pinch-to-Zoom غیرفعال.
   - Double-Tap Zoom غیرفعال.
   - Gesture Zoom سافاری غیرفعال.
   - اندازه Inputها برای جلوگیری از Auto Zoom iOS اصلاح شده.

3) قفل Select / Long Press:
   - متن‌ها و اعداد رابط Select نمی‌شوند.
   - Callout / Context Menu روی UI معمولی باز نمی‌شود.
   - Input و Textarea برای تایپ و ویرایش مستثنا هستند.

4) Motion:
   - جابه‌جایی Home / Finance / Work / Planner نرم و جهت‌دار.
   - Bottom Navigation Active State نرم‌تر.
   - Notification Center با Fade + Slide نرم باز و بسته می‌شود.

5) +MIA:
   - Quick Entry به شکل Bottom Sheet نرم وارد می‌شود.
   - هنگام بستن Reverse Animation دارد.
   - Focus بعد از Motion انجام می‌شود تا پرش کیبورد کمتر شود.

دیتابیس نسخه قبلی بدون تغییر حفظ شده است.
