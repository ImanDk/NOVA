MIA v0.9.1 — Calendar Day Popup + Overdue Alert

اصلاحات تقویم:
- یک‌بار تپ روی روز = فقط انتخاب روز.
- دوبار تپ/دوبار کلیک روی همان روز = Popup واقعی جزئیات همان روز.
- Popup شامل:
  • همه کارهای همان روز
  • برنامه‌های زمان‌دار همان روز
  • وضعیت باز / انجام‌شده / عقب‌افتاده
  • انجام کار، بازگردانی و حذف
  • ویرایش/حذف برنامه
  • افزودن کار جدید برای همان تاریخ
  • افزودن برنامه زمان‌دار برای همان تاریخ
- افزودن کار از Popup بعد از ثبت، Popup همان روز را دوباره باز می‌کند.
- زیر تقویم یک کارت خلاصه از تعداد کارها و برنامه‌های روز انتخاب‌شده نمایش داده می‌شود.

اعلان عقب‌افتاده:
- هر کاری که تاریخش گذشته و Done نشده باشد، از روز بعد وارد Notification Center می‌شود.
- اعلان با رنگ قرمز نمایش داده می‌شود.
- تعداد و عنوان کارهای عقب‌افتاده در اعلان ذکر می‌شود.
- کلیک روی اعلان کاربر را به لیست کارهای باز می‌برد.
