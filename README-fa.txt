MIA v0.9.2 — Single Tap Calendar

تغییرات:
- سیستم دوبار کلیک/دوبار تپ از تقویم حذف شد.
- یک‌بار لمس هر روز:
  • همان روز انتخاب می‌شود.
  • لیست کارها و برنامه‌های همان روز مستقیم زیر تقویم نمایش داده می‌شود.
- لیست روز انتخاب‌شده شامل:
  • Taskهای باز
  • Taskهای انجام‌شده
  • Eventهای زمان‌دار
  • انجام/بازگردانی/حذف Task
  • ویرایش/حذف Event
- دکمه «+ کار» به خود بخش تقویم اضافه شد.
- Task جدید با تاریخ همان روز انتخاب‌شده ثبت می‌شود.
- دکمه «برنامه» هم برای Event زمان‌دار همان روز حفظ شده.
- اگر آیتم‌های روز زیاد باشند، لیست زیر تقویم اسکرول عمودی دارد.
- هشدار قرمز کارهای عقب‌افتاده نسخه v0.9.1 حفظ شده است.
- دیتابیس قبلی حفظ می‌شود.
